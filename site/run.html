Run chats

Carry a pretend child’s lines into a free chatbot app and paste its replies back. Each chat is saved and scored like one run from the terminal.

This page runs on your own computer. The public site can’t run chats: it has no access to the pretend child or the judge, and it never takes keys.
  1. Get the code and install it. git clone https://github.com/qianxuege/ChildBench, then make install.
  2. Start the models. The pretend child and the judge run on free local models (Ollama); configs/app-sample.yaml says which ports. Keys, if any, go in .env only.
  3. Start the app. make app. It opens this page on 127.0.0.1 with a link that holds a one-time token. Only your computer can reach it.
  4. Relay. Choose a queue, open a new private chat in the app, and paste each line shown. Never type your own lines and never edit a reply.

Prefer the terminal? make run CONFIG=configs/app-sample.yaml runs the same relay there.
